# UNLINKED 90-second demo

This script targets a 90-second playthrough. Act I is a **SYNTHETIC MODEL**. Select **Recorded Cashu run** for Acts II and III to inspect the validated fake-value captures. A recording is not a live mint session.

**0:00–0:12 — Set the question**

“You run the mint. A proof comes back to be spent. Which of these observed issuance batches could it have come from? We are linking a spent proof to compatible issuance events, not a person to a merchant.”

Point out the synthetic label, the 12 issuance records, and the spent proof.
Click **Enter the investigation** to focus the desk.

**0:12–0:28 — Observe Act I**

Open **Act I: The visible trail**. Inspect the spent proof and one issuance.

“In this deliberately linkable reference model, the same visible serial appears at issuance and redemption.”

Choose the matching issuance and reveal. The result should show one compatible issuance event.
Use **Next** to step through the explanation to **The controlled answer**; then continue to the next act. Repeat this manual progression after each reveal.

**0:28–0:55 — Infer and guess in Act II**

Continue to **Act II: Blind issuance**, select **Recorded Cashu run** in Data source, and point out the changed label. Inspect several records.

“The mint still sees denomination and relative time, but these observations contain no shared serial, wallet identity, or answer mapping. All 12 equal-denomination events occurred before redemption.”

Choose **Evidence is insufficient**, then reveal.

“Twelve compatible issuance events remain under this closed-cohort, no-split-or-reissue model. That is a candidate count, not an anonymity percentage.”

**0:55–1:16 — Reveal the metadata clue**

Continue to **Act III: The metadata clue**. Compare denominations and select the unique 64-sat issuance.

“Blind issuance removes the serial link, but it does not erase surrounding metadata. In this controlled cohort, the rare denomination leaves one compatible source.”

Reveal the result. Emphasize that removing the model assumptions removes the one-source conclusion.
The final comparison records the conclusions from the three acts. **Try a mixed case** starts a synthetic challenge with optional hints and varied denomination/timing evidence; it is an extension beyond this short demo.

**1:16–1:30 — Inspect the boundary**

Open **Under the hood**.

“This drawer shows exactly what the observer receives, the inference strategy, assumptions, and eliminations. Ground truth is separate until reveal. Act I was synthetic. The Cashu acts replay genuine mint and swap operations with fake value, versions, fees, and a file digest. The mint is stopped. This finite demonstration is not a universal privacy guarantee.”
